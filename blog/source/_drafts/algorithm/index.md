## 数组 Array && 链表 List

- 数组
  - 内存连续，适合**较少**的相同类型的数据
  - 支持随机访问，通过**索引**快速访问数据
- 链表
  - 内存分散，通过指针指向下一个节点，可用于较多的相同类型的数据

遍历方式：

- 单指针
  - 从前往后
  - 从后往前
- 双指针
  - 前后指针
  - 快慢指针
  - 头尾指针向中间靠拢
